# График смен сотрудников

Тестовое задание: Vue 3, TypeScript, Pinia, Vue Router и Laravel 10 (REST API, SQLite).

## Запуск

Нужны PHP 8.1+ с SQLite, Composer и Node.js 22.12+.

```bash
composer install
npm ci
```

Для новой установки скопируйте `.env.example` в `.env`, выполните `php artisan key:generate` и создайте пустой `database/database.sqlite`, если файла ещё нет. Затем:

```bash
php artisan migrate --seed
npm run dev
```

Для существующей базы выполните только `php artisan migrate`: миграция добавляет необязательный `avatar_url`, сохраняя сотрудников, графики и смены. Повторное заполнение демонстрационными данными не требуется.

Во втором терминале запустите `php artisan serve` и откройте http://127.0.0.1:8000. На Windows PowerShell с запретом выполнения `.ps1` используйте `npm.cmd` вместо `npm`.

## Работа с графиком

- Список: поиск по названию, фильтр статуса, независимое сворачивание групп и создание графика.
- Редактор: неделя или весь месяц, переход между периодами, поиск сотрудников, часы за текущий период и покрытие по датам.
- Шаблон можно выбрать, затем нажать пустую ячейку; также работает перетаскивание шаблона и применение к выделению.
- Нажатие на дату открывает быстрое назначение только в свободные ячейки найденных сотрудников.
- Нажатия на пустые ячейки собирают выделение; Ctrl/Shift + клик или пробел позволяют выделить занятую ячейку. «Очистить» удаляет смены, «Снять» убирает только выделение.
- Нажатие на смену открывает редактор времени и удаление. Перетаскивание смены переносит её в свободную ячейку; занятая ячейка отклоняет перенос.
- Разрешена одна смена на сотрудника в день. Время в формате `HH:mm`, окончание строго позже начала; ночные смены через полночь не поддерживаются.
- Изменения локальны до «Сохранить» (черновик) или «Опубликовать». Сохраняется весь график, включая другие периоды. Ошибка запроса не стирает правки; уход со страницы требует подтверждения при наличии изменений.

Шрифт Manrope, иконки и изображения хранятся локально. До 1200 px шаблоны находятся под календарём, до 900 px навигация компактная. Прокрутка дат и сотрудников ограничена календарём; заголовок, сотрудники и покрытие закреплены.
